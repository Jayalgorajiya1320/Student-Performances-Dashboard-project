# Student Performance Dashboard

## Overview
This project is a **Power BI Student Performance Dashboard** designed to analyze and visualize student academic and behavioral performance data. The dashboard helps track student progress, monitor attendance and behavior, and provide actionable insights for teachers, administrators, and educational institutions.

---

## Dashboard Pages

### 1. Main Dashboard
The main dashboard provides a complete overview of student performance using interactive visualizations and KPI cards.

#### Features:
- Student performance summary
- Attendance tracking
- Subject-wise analysis
- Behavioral insights
- Interactive filters and slicers
- KPI cards for quick analysis
- Charts and trend analysis

---

### 2. Student Profile
This page focuses on detailed information about individual students.

#### Features:
- Individual student details
- Academic performance tracking
- Attendance records
- Subject-wise scores
- Performance comparison
- Personalized insights

---

### 3. Tooltip Page
A dedicated tooltip page used for enhanced interactivity.

#### Features:
- Hover-based detailed insights
- Additional metrics display
- Mini visual summaries
- Improved dashboard usability

---
